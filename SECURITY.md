# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Privacy & Data Handling

CSES Pro runs strictly on `cses.fi` pages and stores all user progress, bookmarks, and streak records locally in your browser via `chrome.storage.local` (keyed per CSES username). It does not send any data to external servers or third-party analytics services.

## Reporting a Vulnerability

If you discover a security or privacy vulnerability in CSES Pro, **please do not report it via a public GitHub issue**.

Instead, please report it privately using GitHub Security Advisories:

- [Open a private security advisory](https://github.com/zevrik/CSES-Pro/security/advisories/new)

Please include as much information as possible to help us reproduce and resolve the issue quickly:

- A clear description of the vulnerability and its potential impact
- Step-by-step instructions to reproduce the issue
- Affected version(s) and browser/OS environment
- Any proof-of-concept code or screenshots, if applicable

We will acknowledge receipt as soon as possible and work with you to validate and address the issue before any public disclosure.
